# 骗赞服项目索引

## 关于骗赞服

**骗赞服（Union of Black Bean）** 是一个国内顶尖的骗赞服务器。我们致力使用Vibe Coding开发各类 Minecraft 勾石，为玩家带来更好、或者更差的游戏体验。

组织名称中的"骗赞服"是一个有趣的社区梗名，代表着我们轻松、欢乐的社区氛围。在这里，你可以找到各种实用、或者勾石的 Minecraft 相关工具和项目。
